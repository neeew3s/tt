# Task Tracker

Канбан-таск-трекер на чистом HTML/JS с синхронизацией между устройствами (ПК и телефон).

## Возможности

- Рабочие области (проекты) и задачи в трёх колонках: **Сделать / В работе / Сделано**.
- Создание, **редактирование** и удаление задач и рабочих областей.
- Drag-and-drop перенос задач между колонками.
- **Синхронизация между устройствами** через Upstash Redis.

## Как устроено хранение данных

Все данные хранятся одним JSON-объектом под ключом `tt_state_v1` в Upstash Redis:

1. При открытии приложение сначала пробует загрузить данные из облака (`GET /api/state`) — это источник истины.
2. Если облако недоступно или пусто, берутся данные из `localStorage` браузера.
3. Если и их нет, загружаются демо-данные.
4. Каждое изменение сразу пишется в `localStorage` (кэш) и с небольшой задержкой (дебаунс 400 мс) отправляется в облако (`PUT /api/state`).

Благодаря этому на телефоне и на ПК — одни и те же проекты. Если сервер недоступен, приложение продолжает работать локально и покажет предупреждение.

> Модель синхронизации — «последний сохранивший побеждает» (last-write-wins), без авторизации. Для одного пользователя этого достаточно.

## Структура проекта

- `index.html` — интерфейс (всё в одном файле).
- `api/state.js` — бессерверная функция Vercel (GET/PUT состояния), работает на дефолтном Node.js-рантайме.
- `bg_final.jpg` — фоновое изображение.

## Локальный запуск

Просто откройте `index.html` в браузере — приложение работает офлайн на `localStorage`.
Для проверки синхронизации локально:

```bash
npm install          # ставит vercel CLI и @upstash/redis
npm run dev          # vercel dev — поднимает локальный сервер с /api
```

## Деплой на Vercel

1. Зарегистрируйтесь на [vercel.com](https://vercel.com) и импортируйте репозиторий.
   - Framework preset можно оставить **Other** (Vercel сам определит статику + функции).
2. Создайте базу **Upstash Redis**:
   - **Вариант А (проще):** Dashboard → **Storage → Create → Redis → Upstash**. Vercel сам подставит переменные `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN`, либо одиночный `REDIS_URL` — код поддерживает оба варианта.
   - **Вариант Б:** создайте бесплатную Redis-базу на [console.upstash.com](https://console.upstash.com) и добавьте в проект переменные окружения `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` (вкладка **Settings → Environment Variables**).
3. Задеплойте (Redeploy), чтобы подхватились переменные.

> Примечание: `Vercel KV` больше не существует (его убрали в декабре 2024). Вместо него — интеграция **Upstash Redis**, которая и используется здесь.

Без Redis приложение всё равно задеплоится и будет работать локально (localStorage), но без синхронизации между устройствами.
